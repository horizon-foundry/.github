# Horizon Foundry

Open-source product and engineering tools, created and maintained by **[Craig Martin](https://github.com/cjmartin2)**.

Horizon Foundry is a product and engineering company. It works with companies on product, technology and AI decisions that are costly to get wrong, and builds products of its own.

## Projects

**[Foundry](https://github.com/horizon-foundry/foundry)**
Software delivery integrity as Claude Code skills. Frame, scaffold, document, instrument, and audit AI-built software before it ships, ending in a scope-qualified ship or no-ship verdict.

```bash
npx skills add horizon-foundry/foundry
```
